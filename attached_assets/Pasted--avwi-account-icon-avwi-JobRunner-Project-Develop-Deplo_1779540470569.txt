a9b0493 · Revert Liquid Glass — content was dropping out in Live Activity context Latest screenshots showed the status pill missing entirely from both lock-screen and expanded Dynamic Island, and the timer column also missing in some lock-screen presentations. The common factor: both elements were wrapped in `.glassEffect()` ViewModifiers. Liquid Glass material works for home-screen widgets and standalone SwiftUI views, but the Live Activity render context appears to reject it — the views end up with zero geometry instead of falling back gracefully. Reverting both `StatusPillBackground` and `TimerGlassBackground` to their pre-glass paths: - StatusPillBackground: always a capsule fill at 15% status colour opacity. Same as commit ac63567e's pre-glass design. - TimerGlassBackground: removed entirely. LiquidTimerColumn (name retained for diff readability) is now a plain trailing VStack at 92pt width with no backing — matches the original timer column from the polish pass. Removed inner .padding(.horizontal, 10) + .padding(.vertical, 6) from LiquidTimerColumn — those were sized for the now-removed glass backing, leaving the text floating with phantom padding. Card now matches the layout from commit ac63567e (the version the user described as "great progress"). The Liquid Glass demo is over — the iOS 26 material isn't viable here. Other polish (status pill shape, small caps tracking, brand halo removed, hairline separator) all stays. Co-Authored-By: Claude Opus 4.7 <noreply@anthropic.com>
