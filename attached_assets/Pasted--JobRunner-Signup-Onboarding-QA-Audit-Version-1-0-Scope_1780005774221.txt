## SECTION 2 — SIGNUP FORM (STEP 1)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

### 2A — Field Presence & Labels
[ ] Full name field present and labelled
[ ] Email field present and labelled
[ ] Password field present and labelled
[ ] Confirm password field present (or inline confirmation)
[ ] Business name field present
[ ] Phone number field present (Australian +61 format supported)
[ ] Trade/industry selector present (plumber, electrician, builder, etc.)
[ ] Terms & Conditions checkbox present with working link
[ ] Privacy Policy link present and working
[ ] "Already have an account? Log in" link present

### 2B — Validation: Empty Submission
[ ] Submitting blank form shows inline errors on ALL required fields
[ ] Error messages are specific (not just "required") — e.g. "Email is required"
[ ] Page does not scroll to top on failed validation
[ ] Submit button shows loading state while processing

### 2C — Email Validation
[ ] Accepts: user@domain.com.au
[ ] Accepts: user+tag@domain.com
[ ] Rejects: missing @ symbol → inline error
[ ] Rejects: no domain (user@) → inline error
[ ] Rejects: no TLD (user@domain) → inline error
[ ] Rejects: spaces in email → inline error
[ ] Rejects: already-registered email → specific error "Email already in use"
[ ] Case-insensitive: User@Domain.Com treated same as user@domain.com

### 2D — Password Validation
[ ] Min length enforced (8+ chars recommended) → error if too short
[ ] Password strength indicator visible (weak/medium/strong)
[ ] Password is masked by default
[ ] Show/hide password toggle works
[ ] Confirm password mismatch → inline error "Passwords do not match"
[ ] Accepts special characters (!@#$%^&*)
[ ] Does NOT accept passwords that are just spaces

### 2E — Phone Number
[ ] Accepts 04XX XXX XXX (Australian mobile)
[ ] Accepts +61 4XX XXX XXX (international format)
[ ] Rejects letters → inline error
[ ] Rejects < 10 digits → inline error
[ ] Rejects > 15 digits → inline error

### 2F — Business Name
[ ] Accepts special chars (O'Brien Plumbing, Smith & Sons)
[ ] Accepts numbers (ABC Electrical 2024)
[ ] Rejects empty → inline error
[ ] Max character limit enforced (suggest 100 chars)

### 2G — Terms Checkbox
[ ] Cannot submit without ticking → inline error "You must accept the terms"
[ ] Checkbox is keyboard-accessible (space bar toggles)

### 2H — Duplicate Account Prevention
[ ] Attempting to register with an existing email shows clear error
[ ] Does NOT create a duplicate account silently
[ ] Error appears inline (not as a full page redirect)

### 4A — Welcome / Setup Wizard
[ ] First login lands on onboarding/setup screen (not raw dashboard)
[ ] Progress indicator visible (Step 1 of N)
[ ] User's business name populated from signup
[ ] Can navigate back through steps without losing data
[ ] Can skip optional steps (marked clearly as optional)
[ ] Skipped steps accessible later from settings

### 4B — Business Profile Setup
[ ] Business logo upload works (PNG, JPG, WEBP accepted)

[ ] Can skip team setup if solo operator
[ ] Role permissions enforced from first login

### 4D — Integrations Setup (Xero, etc.)

[ ] Skipping Xero doesn't break anything downstream

### 4E — Onboarding Completion

[ ] Completion message or celebration state shown
[ ] Onboarding checklist doesn't re-appear after completion
[ ] "Get started" / first-run tips shown on dashboard (dismissable)
[ ] Dismissed tips don't reappear on next login
