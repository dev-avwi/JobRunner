The important distinction

There are really 3 levels here:

1. Truly native iOS

Actual system components:
	•	native navigation back button
	•	native alert
	•	native action sheet
	•	native share sheet
	•	native switch

These are controlled by iOS itself.

2. Custom but very Apple-like

Built by you / React Native / Expo, but styled to feel like modern iOS.

This is what your screenshots most likely are.

3. Custom but off

What you have now in some places, where the feel drifted away from that polished Apple-family look.
