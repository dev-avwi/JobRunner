Short answer: no, Expo Go won't work for JobRunner.

Your app uses too many native modules that aren't in the Expo Go shell:

Stripe + Stripe Terminal (Tap to Pay)
Twilio voice/Vapi.ai SDKs
@gorhom/bottom-sheet with reanimated/gesture-handler (works, but...)
Sentry native, expo-notifications with custom config, IAP, location background tracking, SQLite offline, etc.
Expo Go gives you a fixed bundle of modules — anything custom (or any version mismatch) just crashes or silently no-ops. You'd spend more time fighting "this works in Expo Go but not production" than just doing builds.

Better options that skip the 20-minute EAS rebuild loop
1. Development Build + hot reload (recommended) — Build the dev client once, then iterate via Metro:

eas build --platform android --profile development

Install that .apk on your phone one time. After that, run npx expo start --dev-client and your phone reloads JS instantly on save — same speed as Expo Go, but with all your real native modules. You only need a new build when you add/upgrade a native package or change app.json native config.

2. EAS Update (OTA) for JS-only changes — For pure UI/JS tweaks (like the font fix I just shipped), publish an OTA:

eas update --branch production --message "Android typography fix"

Existing installs pull it in seconds. No store review, no build wait. Native config changes still need a real build.

3. Local Android build — If you have Android Studio, npx expo run:android builds and installs on your device in ~3 minutes vs EAS's 15-20.

What I'd recommend for you specifically
Given how many polish rounds we're doing:

Make a development build once (option 1) — then every font/layout/JS change is live in <2 seconds
Push OTA updates (option 2) for the changes already merged so you can see them on your existing install without waiting for build #38
Want me to add a "dev" profile to eas.json if it's not already there, and walk through the dev-client setup? That single change would save you hours over the next few rounds.
