**The iframe problem is a genuine blocker we missed**

This is the most important thing in Replit's entire response. You cannot embed arbitrary websites in an iframe. Most production apps block it with X-Frame-Options and CSP headers. If you try to build "the app loads inside our dashboard" the way the spec described, it will fail on the majority of real apps users submit. This is a real blocker that wasn't in the 24 problems and should have been.

Replit's solution is exactly right. Browser extension that records user actions on their actual browser tab, sends the event log back to your server, Playwright replays it server-side. Record locally, replay on the server. This is how tools like Playwright's own codegen works. It solves the iframe problem entirely and is simpler to build than a cloud browser infrastructure.

This is the smartest thing Replit has said in this entire conversation. The live streaming vision — three concurrent real-time systems per user staying in sync — is complex, expensive, and fragile. Replit's alternative produces the exact same user experience with fundamentally more reliable technology.

Run the Playwright replay and Claude analysis as a batch job. Capture raw video. Get all analysis results. Compose the final video with annotations timed to appear at exactly the right moments. Then play it back to the user.
