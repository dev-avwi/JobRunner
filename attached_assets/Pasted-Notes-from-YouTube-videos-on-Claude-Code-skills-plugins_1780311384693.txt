## The 6 Skills

### 1 — G Stack (Gary Tan, YC President)

A bundle of 23 skills designed for founders, CEOs, first-time Claude Code users, and tech leads. Built by Gary Tan specifically for building software products.

**Key skills inside the bundle**:

- `/office-hours` — describe what you want to build, G Stack asks clarifying questions about the pain and why you're building it
- `/plan` — creates a structured build plan
- `/ceo-review` — reviews the plan from a CEO/product perspective
- `/review` — code review
- `/qa` — quality assurance

**How to install**: copy the installation paragraph from the G Stack repo (link in video description), paste into Claude Code terminal, press enter, say yes to proceed. It installs all 23 skills automatically.

**When to use**: any software product build. The office-hours → plan → CEO review → engineering review → QA sequence prevents vibe-coded projects that aren't actually useful.

---

### 2 — Hostinger MCP

Brings full deployment capability into Claude Code. Instead of leaving the terminal to buy a VPS or configure hosting, you just say "deploy my app" and Claude handles it.

**What it can do**: create VPS, manage snapshots, buy domains, check domain availability, configure DNS, deploy sites — all from the terminal.

**How to install**:

1. Get a Hostinger account (Business plan recommended — up to 50 websites, free domain, Node.js support)
2. Go to Hostinger API page → copy the MCP config
3. In Claude Code: `add this MCP server to my configuration` + paste the config
4. Generate an API token in Hostinger (never → generate → copy)
5. Tell Claude Code to add the token to the MCP config
6. Type `/new` then `/mcp` — Hostinger MCP should appear with 118 tools

**Live demo**: told Claude "create a simple website that says Hi, my name is Tim and deploy to tim.[domain]" — site was live in seconds without touching a UI.

**Note**: register your domain first (fill in contact info/registrant details) before pushing a site — this is required for the deployment to work.

---

### 3 — Firecrawl

Lets Claude crawl and scrape the web far more reliably than its built-in browser. Solves: rate limiting, CAPTCHAs, blocks, and failed page loads that the native Claude browser hits.

**What it does**: bypasses security features that block automated access, crawls at scale, extracts structured data from pages.

**Example**: crawled 300+ pages from a Y Combinator company directory in ~10 minutes, extracted company names, founders, fundraising stage, what they do — all as a structured markdown file. Zero manual intervention.

**Cost**: free tier = ~1,000 credits/month. 300 pages used ~312 credits. Paid tiers available if you need more volume.

**How to install**: make a free account at firecrawl.dev, copy the skill file from the main page, paste into Claude Code with "can you add this skill for me" — it installs the pnpm CLI automatically.

**How to use**: type `/firecrawl` to invoke it, then describe what to crawl and what to extract.

---

### 4 — Humanizer

Makes Claude's text output sound more like a human. Flags overused AI patterns (m-dashes, recycled words, capitalisation) and rewrites in a more natural, lowercase, conversational register.

**When to use**: emails, social media posts, client-facing responses, any text that shouldn't scream AI-generated.

**How to install**: copy 2 lines from the git repo, tell Claude Code "add this skill", paste the lines.

**How to use**: `/humanize` + paste any text → get a rewritten version.

---

### 5 — Composio

Solves the tool bloat problem. Instead of connecting every tool (Gmail, Google Drive, Notion, Meta Ads, etc.) directly to Claude Code and bloating the context window with 200 tool definitions, you connect everything to Composio once. Claude Code then calls Composio on demand and only fetches the tool it needs at that moment.

**Benefits**:

- More token efficient — tools loaded on demand, not all at once
- Higher accuracy — Claude discovers the right tool rather than confusing similar ones
- Cross-machine persistence — connect tools once in Composio, works on any machine you install Claude Code on
- Supports thousands of apps from one dashboard

**Free tier**: 20,000 tool calls/month. Paid: ~$20/month.

**How to install**: go to Composio (v4.1), connect apps you want, go to Install → Claude Code → copy the prompt with your API key → paste into Claude Code → restart session → test with a task.

---

### 6 — VibeSec

Security audit skill. Scans your codebase for vulnerabilities before you deploy to production.

**What it catches**: exposed API keys, unauthenticated data access, SQL injection risks, insecure routes, and other common vibe-coding security mistakes.

**Key insight**: install it *before* you start building, not just at the end. It teaches Claude Code to think through vulnerabilities as it writes code, not just flag them after.

**Demo result**: ran on a deployed accounting app (already live) → found multiple real vulnerabilities → auto-fixed them. "Good thing I ran this because I actually had this app deployed."

**How to install**: copy the Claude Code installation instructions from the VibeSec repo, paste into Claude Code with "add this to my Claude Code skills". Then run `/vibesec` to audit any project.

### Skill 1 — Skill Creator (Official Anthropic)

The meta-skill. Builds every other skill. You describe what you want in plain English → Claude drafts the skill → tests it → iterates → packages it into a reusable `.md` file.

**Why it matters**: most people try to write skills manually, hit a wall with formatting and structure, and give up. Skill Creator removes that wall entirely.

**Install**: `/pluginstall skill-creator`

**Install globally** (recommended) — then it's available in every project automatically.

**Practical use**: describe any repeatable business process (e.g. "write property descriptions from these inputs") → Skill Creator packages it into a reusable skill → give that skill to the client or use it across all similar clients.

> "Drop in an SOP and it turns that into a reusable skill."
> 

---

### Skill 2 — Superpowers (150K+ GitHub stars)

Forces Claude to work like a senior developer: plan first, write tests before code, work in an isolated environment, do two-stage review (does it match the spec? is the code quality good?). Prevents the #1 failure mode — code that looks fine but falls apart when clients run it.

**Why it matters**: without a framework like this, Claude sprints to write code and misses edge cases. With Superpowers, you get from 60% → 80% on the first pass. Fewer debugging cycles = less time + lower token costs.

**Install**: command shown on screen in video / in description.

**When to use**: any production software. If a client's business depends on it working, run Superpowers.

---

### Skill 3 — GSD (Get Shit Done)

Fixes context rot — the degradation that happens when Claude forgets requirements mid-session as the context window fills up.

**How it works**: instead of one long session, GSD spawns fresh sub-agents for each task. Each sub-agent has a clean context window focused only on what it needs. Main session stays clean. Built-in quality gates catch scope reduction (when Claude silently drops a requirement you asked for) and security issues.

**Also has**: autonomous mode — give Claude a spec, walk away, it plans/executes/commits without babysitting.

**Token cost**: GSD uses more tokens (sub-agents cost tokens) but saves hours of rework from context rot. Net positive.

**Install**: command in video description. Then `/gsd-help` inside Claude Code to see available commands.

**How Superpowers + GSD work together**: Superpowers gives Claude the right process (plan, test, review). GSD gives Claude clean context so that process actually works every time.

---

### Skill 4 — /review and /ultra review (Built-in, no install needed)

**`/review`** — fast, local, free (beyond normal usage tokens). Structured code review: bugs, edge cases, design issues. Run this after every meaningful coding session.

**`/ultra review`** — launched with Opus 4.7. Uploads your branch to a cloud sandbox → spins up a fleet of parallel reviewer agents → each attacks from a different angle (logic, security, performance, edge cases) → bugs must be independently reproduced before they appear on your list. No false positives, no style nitpicks. Confirmed bugs only.

**Requirements for /ultra review**: Claude Code version 2.1.86+, signed in with a Claude account (API key alone won't work).

**Cost**: Pro/Max get 3 free runs. After that: $5–20 per run depending on codebase size.

**When to use**: `/review` for everything. `/ultra review` before merging anything that touches payments, auth, database migrations, or major refactors.

**The workflow**: plan with Superpowers → execute with clean context (GSD) → `/review` → `/ultra review` before merging anything critical.

---

### Skill 5 — Context Mode

Solves two problems: garbage accumulating in your context window, and Claude forgetting what it was doing after a compaction.

**Problem**: every tool call dumps raw data into context. A Playwright snapshot = 56KB. 20 GitHub issues = 59KB. After 30 minutes, 40% of your context is garbage Claude never needs to look at. When context compacts, Claude forgets files it was editing, tasks in progress, and your last request.

**Solution — part 1 (garbage out)**: routes tool calls through a sandbox. Raw output captured, only what Claude actually needs comes back. Result from their benchmarks: 56KB Playwright snapshot → 299 bytes. 46KB access log → 155 bytes. Full session: 315KB → 5KB total.

**Solution — part 2 (memory across compaction)**: tracks every meaningful event (file edits, decisions, errors, task states) in a local SQLite database. When Claude compacts, Context Mode rebuilds a session snapshot and injects it back. Claude picks up exactly where it left off.

**Result**: sessions that used to fall apart at 30 minutes now run for 3 hours.

**Install**: two commands in terminal → restart Claude Code. Plugin auto-installs MCP server, hooks, and routing instructions.

**Check stats**: `/context-mode:ctx-stats` at any point to see your own compression numbers.

---

### Skill 6 — Claude Mem

Carries knowledge across sessions, not just within one. Every new Claude Code session starts from scratch — you re-explain the project, re-establish context, waste tokens. Claude Mem fixes this.

**How it works**: hooks into Claude's session lifecycle → captures file edits, decisions, bug fixes, commands → compresses into semantic summaries → stores in local SQLite with vector search → on new session start, relevant parts are automatically injected back in.

**Also**: auto-generates and updates folder-level `claude.md` files as you work. Project documentation writes itself.

**Retrieval efficiency**: 3-layer search (compact index → timeline → full details for the specific handoff needed). ~10x token savings on retrieval vs. dumping everything in at session start.

**Result**: open a project you haven't touched in 2 weeks → Claude already knows what you were working on, what decisions you made, where you left off.

**Install**: two specific commands (shown on screen). Warning from the repo: don't run just the npm install command — that installs the SDK library only and hooks never register. Use the two commands shown.

## What a Skill Actually Is

A skill = a saved instruction set that Claude reads before doing any work. A markdown file that holds your design system, preferences, stack, and client context. Write it once, Claude loads it automatically. Same prompt + same Claude + skill loaded = dramatically better output.

> "It stops being a generic AI designer and starts feeling like a collaborator who knows your actual work."
> 

## The Four Essential Design Skills

### 1 — Front-End Design (Anthropic-official)

**What makes it work**: it explicitly tells Claude what *not* to do. "Never use generic AI-generated aesthetics like overused font families, clichéd colour schemes." Gives Claude a brief lesson on creativity and thoughtfulness. The result is consistently more editorial, bolder, and more unique.

**Before**: purple gradients, white background, soft shadows, emojis, improper card alignment — screams AI-generated.

**After**: custom cursor, fade-in scroll animations, nicely laid out cards with hover states, serif + sans-serif pairing, smooth scroll anchors that actually work.

**Install via Claude Code**: download zip from GitHub → Customize Skills → + → Create Skill → Upload a Skill → drop the zip in. Toggle on. Use `/front-end-design` slash command.

**Edit it**: open the dropdown → Edit with Claude → describe changes (e.g. "only use sans-serif fonts, examples: Geist, Google Sans, DM Sans") → Claude updates the `.md` file.

---

### 2 — Impeccable

Teaches Claude about typography, colour and contrast, spatial design, responsiveness, interaction design, motion design, and UX writing — *before* any command runs.

**22 slash subcommands**, including:

- `/impeccable` — full redesign
- `/impeccable:animate` — adds animations as it sees fit
- `/impeccable:colorize` — adds colour intelligently
- `/impeccable:quieter` — reduces visual loudness (gradient text, heavy weights, emojis) and adds elegance
- `/impeccable:audit` — five-dimensional quality check with severity rankings
- `/impeccable:document` — generates a `design.md` file capturing your full design system so any AI agent can read it every time

**Install**: single one-line command from the Impeccable landing page, paste into Claude Code.

**The "slob tab"**: Impeccable's landing page lists design patterns it teaches Claude *not* to use. Worth reading yourself — it's a crash course in what currently looks AI-generated (side tab accent borders, gradient text everywhere, emoji icons, heavy font weights on every heading).

**Actively maintained**: creator is building `/live` — iterate on your UI directly in the browser.

### 3 — UI UX Pro Max

Packed with: 57 UI styles, 95 colour palettes, 56 font pairings, 8 tech stacks. The main differentiator: **it tells Claude to think, not just do**. Claude searches its design database to find what aspects of the skill are relevant to what you're building, then generates code, then runs a quality checklist.

**Key learning**: "You need to understand not just which skills are helpful, but how to use them by communicating exactly what you want." If Claude doesn't make a drastic change with the skill, tell it explicitly: "Use the skill to do a more drastic redesign. UI UX Pro Max has an extensive library of colour palettes and font pairings — use them to their full advantage."

**Install**: single one-line command, paste into Claude Code.

**Edit it**: you can open the `.md` file directly and delete patterns you never want (e.g. glassmorphism). Or just tell Claude via prompt: "never use glassmorphism again."

### 4 — Web Design Guidelines (Vercel Labs)

Not for initial design — for auditing before you ship.

Teaches Claude a comprehensive list of web interface guidelines: keyboard navigation works everywhere, never disable zoom, don't block paste, loading indicators for buttons, accessible forms, animation best practices, layout standards, and much more.

## How to Build Your Own Skill

In Claude Code → Customize Skills → + → Create Skill → **Create with Claude**

Claude asks: what should the skill do? Answer in plain language. It then asks follow-up questions:

- What should the skill govern?
- Who's the primary audience for designs produced with this skill?
- Spacing and sizing rules?
- Preferred tech stack/output?

Be thorough. Claude generates a detailed `.md` file, a references folder, Tailwind design tokens if you use Tailwind, and typography pairings.

**Example custom skill output**: SaaS UI Design skill with instructions to always identify product type first (dashboard vs landing page vs mobile — different design principles), infer the goal of the screen before designing (what actions matter most, what should users notice first), default to restrained palette with neutral backgrounds, one primary body font + one display font for large headings.

Result from a single prompt using the custom skill: a clean, sleek LLM startup landing page with a primary teal CTA, dynamically generated code-based graphics in the hero section. "I'm really happy with how it's looking from just a first prompt."

## Apply to Your Projects

- **Impeccable `/document`** — after you get a design you're happy with for any of your apps, run this. It generates a `design.md` capturing your full design system. Every future Claude Code session reads it automatically. This is how you maintain visual consistency across sessions without re-explaining everything.
- **The `/quieter` command** — if any screen feels visually busy or overwhelming, this is the single fastest fix. One prompt, Claude audits the loudness and reduces it intelligently.
- **Build a custom skill for each app** — Kindred, Criti, and JobRunner each have distinct brand personalities. A custom skill per app means every new screen starts from the right foundation without any prompting overhead.
- **Web Design Guidelines before shipping any public page** — the annotation mode (marking up issues directly on the live page in orange) is the most efficient accessibility review workflow in the library. Run it before any landing page goes live.
- **Type UI for visual direction** — when you're starting a new screen and know the feeling you want (editorial, bold, minimal, warm) but can't articulate it in design language, browse Type UI visually and pick the skill that matches.
