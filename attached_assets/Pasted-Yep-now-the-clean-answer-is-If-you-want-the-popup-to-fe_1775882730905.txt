If you want the popup to feel like the newer iOS glass family, stop trying to fake it with a plain Modal + white card + custom pill buttons. React Native’s Modal is only a basic presentation layer, and Alert gives you a real system alert but only for the standard alert layout, not your custom content-heavy popup.  ￼

For a custom popup that still feels “native glass,” the closest path in Expo is to rebuild the popup family using native iOS glass material with Expo GlassEffect, which renders native iOS liquid glass using UIVisualEffectView. Expo also documents BlurView for blurred surfaces, but GlassEffect is the closer match for the newer liquid-glass material language.  ￼

	•	keep the card layout custom, because there is no built-in React Native “latest iOS 26 custom dialog” component you can just drop in
	•	reserve Alert.alert() only for simple system-native alerts where the standard alert layout is acceptable.  ￼
