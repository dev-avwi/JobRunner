Commit 113776ff (Task #61, 2026-05-19) added this to satisfy a TS error about styles.card being missing:

+  card: {
+    backgroundColor: colors.card,
+    borderRadius: radius.xl,
+    borderWidth: 1,
+    borderColor: colors.cardBorder,
+    ...shadows.sm,
+  },

The moment that definition landed, the wrapper at line 1287 became a real bordered, shadowed card. Same JSX, new visible style. So Task #61 didn't add a wrapper — it activated an orphan style reference that had been quietly broken since April.
